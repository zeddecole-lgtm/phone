# HiddenBox — تطبيق حاوية يشغّل تطبيقات أخرى داخله

تطبيق أندرويد يسمح لك باختيار ملف **APK** وتثبيته **داخل بيئة معزولة** بداخل التطبيق،
ثم تشغيله من هناك. التطبيق المثبَّت بهذه الطريقة **لا يظهر** في قائمة تطبيقات الهاتف
ولا في الإعدادات — هو موجود فقط داخل HiddenBox ويعمل فقط عند تشغيله من قائمته.

مبني فوق محرك المحاكاة مفتوح المصدر **BlackBox / NewBlackbox** (رخصة Apache 2.0).
الكود الخاص بالواجهة تحت `com.hiddenbox.app`، والمحرك في وحدة `Bcore`.

---

## كيف يعمل (باختصار)

1. عند فتح التطبيق، الكلاس `App` يُهيّئ المحرك في `attachBaseContext` قبل أي شيء آخر.
2. تضغط زر **+** فتختار ملف APK من الهاتف.
3. يُنسخ الملف مؤقتاً ويُثبَّت داخل البيئة عبر `installPackageAsUser` — **لا** يُسجَّل في نظام أندرويد.
4. يظهر التطبيق في الشبكة. ضغطة = تشغيل داخل البيئة. ضغطة مطوّلة = حذف.

الملفات المهمة:

| الملف | الوظيفة |
|------|---------|
| `app/.../App.kt` | تهيئة المحرك + **تعطيل إرسال السجلّات لجهة خارجية** |
| `app/.../VirtualCore.kt` | غلاف مبسّط حول المحرك (قائمة/تثبيت/تشغيل/حذف) |
| `app/.../MainActivity.kt` | الواجهة: الشبكة، اختيار APK، الأذونات |

> **ملاحظة خصوصية:** المحرك الأصلي يرفع `logcat` كامل الجهاز ومعلوماته إلى خادم
> خارجي عبر معرّف مُضمَّن افتراضياً. في `App.kt` جعلنا `getLogSenderChatId()` تُعيد
> نصاً فارغاً فأصبحت هذه الميزة معطّلة بالكامل.

## طريقة البناء

تحتاج الـ **Android SDK**، ولذلك البناء يتم إمّا على جهازك أو عبر GitHub Actions
(لا يمكن تنزيل الـ SDK داخل بيئة المحادثة هذه).

### الخيار الأول: Android Studio (الأسهل)
1. ثبّت Android Studio (أحدث إصدار) + **JDK 17 أو 21** + **NDK 29.0.13846066**.
2. افتح مجلد المشروع `HiddenBox`.
3. انتظر مزامنة Gradle، ثم: `Build > Build APK(s)`.
4. الناتج في `app/build/outputs/apk/debug/`.

### الخيار الثاني: سطر الأوامر
```bash
cd HiddenBox
./gradlew assembleDebug        # نسخة تجريبية
# أو
./gradlew assembleRelease      # نسخة موقّعة بمفتاح debug
```

### الخيار الثالث: GitHub Actions (بدون تثبيت أي شيء)
1. ارفع المجلد إلى مستودع GitHub جديد.
2. ملف `.github/workflows/build.yml` يبني الـ APK تلقائياً عند الرفع.
3. نزّل الناتج من تبويب **Actions → آخر تشغيل → Artifacts**.

## التثبيت على الهاتف
- فعّل «تثبيت من مصادر غير معروفة» لمتصفّح/مدير الملفات الذي ستفتح به الـ APK.
- ثبّت `HiddenBox_*_universal.apk` (أو ملف المعمارية المناسبة: `arm64-v8a` لأغلب الأجهزة الحديثة).
- من أندرويد 11+، امنح التطبيق إذن «الوصول لكل الملفات» عند طلبه، فبعض التطبيقات تحتاجه للعمل داخل البيئة.

---

## حدود ومشاكل متوقعة
- **ليست كل التطبيقات تعمل.** تطبيقات البنوك والألعاب ذات الحماية، وأي تطبيق يكتشف
  البيئات الافتراضية، قد يرفض العمل أو ينهار.
- الاستقرار غير مضمون؛ المحرك نفسه يصفه مطوّره بأنه «لأغراض التعلّم والتجربة».
- لن يُقبل التطبيق في Google Play (سياسة تحميل وتشغيل كود خارجي) — وزّعه كـ APK.
- يدعم معماريات `arm64-v8a` و`armeabi-v7a`.
- استخدم هذا فقط مع تطبيقات تملك حق استخدامها؛ أنت مسؤول عمّا تثبّته داخله.
